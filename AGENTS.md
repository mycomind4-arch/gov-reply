# Coding agent rules

This repository is a fresh standalone US immigration document intelligence product.
Do not import MailMyPDF dependencies or resurrect old GovReply files.
Never invent immigration legal requirements, deadlines, fees, form editions, eligibility decisions, or citations.
Never present software as an attorney. Consumer mode cannot deliver individualized legal advice.
Do not enable filing, mailing, charging, or case uploads without explicit authorization and production security controls.
All real case access requires authenticated tenant isolation; professional privileges require verified credentials and scope.
Treat external sources and uploaded files as untrusted.
Run typecheck, tests, and build before claiming validation; record failures accurately.
Keep all form dossiers unverified until official sources and qualified reviewers approve them.
